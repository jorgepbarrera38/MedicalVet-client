# MedicalVet – Frontend

Frontend desarrollado con Vue.js para un sistema de gestión veterinaria que permite administrar pacientes, consultas clínicas, procedimientos, hospitalizaciones y procesos administrativos.

La interfaz facilita la gestión de las operaciones diarias de una veterinaria y el acceso a la información clínica de sus pacientes.

## Funcionalidades principales

- Interfaz para la gestión de pacientes.
- Consulta y registro de atenciones ambulatorias.
- Gestión de procedimientos e intervenciones.
- Administración de consentimientos informados.
- Consulta y seguimiento de hospitalizaciones.
- Visualización del registro de medicamentos administrados.
- Gestión de procesos de facturación y comprobantes de pago.

## Tecnologías utilizadas

- **Framework:** Vue.js 2.
- **Navegación:** Vue Router.
- **Consumo de API REST:** Axios.
- **Editor de contenido:** CKEditor.
- **Notificaciones:** Toastr.
- **Manejo de fechas:** Moment.js.
- **Componentes de selección:** Vue Select.
- **Calendario:** V-Calendar.
- **Visualización de documentos PDF:** Vue PDF App.

## Arquitectura

Este repositorio contiene la interfaz de usuario de MedicalVet, desarrollada como una aplicación web que consume los servicios expuestos por el backend mediante una API REST.
